# Contributing Guidelines

Thank you for your interest in contributing!

This repository is designed to help beginners practise open-source
contributions in a friendly learning environment.

## Step 1: Find an Issue

Open the Issues tab and select a task that you understand.

Read the full description and check the comments before starting.

## Step 2: Ask Before Starting

If the issue asks contributors to request permission, leave a comment
explaining that you would like to work on it.

Wait for a response when the project requires approval.

## Step 3: Fork the Repository

Create your own copy of this repository using the Fork button.

## Step 4: Make a Small Change

Start with a small, useful improvement, such as fixing a typo or
improving a sentence.

## Step 5: Create a Pull Request

Explain what you changed, why you changed it, and how you checked it.

Compare your branch with the original repository's main branch.

## Step 6: Communicate Respectfully

- Be polite and patient.
- Read the project instructions before asking questions.
- Explain problems clearly.
- Accept feedback positively.
- Do not submit changes you do not understand.

## Important

This is a learning repository. Please make genuine, useful changes
rather than creating meaningless edits just to open a pull request.

Happy contributing!
